| `bevy_speech_bubbles` | `src/dialogue/bubble.rs` | Camera marker is a type parameter — see below. |

All ten repos (six new + four `emerge-*`) are **private** under `Ladvien/`, pushed via
`scripts/mirror_crates.sh` (`git subtree split`, history intact, re-runs to `Everything up-to-date`).
`publish = false` on every new crate, so nothing can reach crates.io by accident.

**Licensing is split on purpose:** the six extracted crates are MIT OR Apache-2.0 (a GPL crate in the
Bevy ecosystem is unadoptable); `emerge-*` stay GPL-3.0 with the game.

**The pattern to reuse: facade newtypes, not traits.** A `trait CellMap` cannot work — call sites pass
`&dungeon` where `dungeon: Res<Dungeon>`, inference picks `M = Res<Dungeon>`, and the orphan rule forbids
implementing a foreign trait for it, so all ~40 sites would need `&*dungeon`. `&dyn` puts a virtual call
in the diffusion inner loop. The game keeps `Stig(StigGrid<10>)` / `LightField { core, dirty }` with
today's exact signatures, delegating. **Zero call sites changed.** Occlusion enters as
`los: impl Fn(IVec2, IVec2) -> bool` — monomorphised at the call site, returns a `bool`, so it cannot
perturb a float.

No golden moved through any of it. `replay::field_passes_are_bit_identical` (3s) was the gate.

### 2. The empty-archive fix — every offline search was producing nothing

`minimal_criterion` rejected **every** episode with `"no crab died — the world was static"`, so
`train` wrote empty archives and exited 0. `search_parallel` died on its `filled > 0` precondition, which
means its determinism assertions had **never run**.

Cause is the evaluation harness, not the game: `run_episode`'s synthetic player alternates
`DWELL_ADVANCES × ADVANCE_TICKS` windows under a standing `MoveOrder` (which excludes units from
`unit_actions`/`medic_heal`) with one `ENGAGE_TICKS` window — and when a containment device is thrown, it
holds weapons tight for that whole window. The only window the brain controls is the one where the squad
deliberately does not shoot.

Fix: a **completed containment** now resolves an episode alongside a kill. Both clauses needed it —
`0x5C09191` takes zero damage, so relaxing only "no crab died" would still have been rejected by "nothing
was at stake". It cannot move a golden (the criterion runs *after* the rollout), which is a correction to
`BACKLOG.md`'s claim that every candidate fix would.

Went green: both `search_parallel` tests and
`search_calibration::the_authored_brains_produce_a_real_encounter_on_every_world` (its skip is deleted).

### B. Two CI skips — the "brain barely runs" defect

```
--skip shipped_level_playtests_and_is_deterministic
--skip a_candidate_genome_actually_changes_the_simulation
```

Different cause from the criterion, and **not** fixed by it. The brain controls only 25% of a hub cycle
(`DWELL_ADVANCES × ADVANCE_TICKS + ENGAGE_TICKS` = 1200 ticks), so two genomes hash identically, and
`playtest_level`'s 1800-tick horizon barely reaches one engage window.

Candidates: shorten `ADVANCE_TICKS`/`DWELL_ADVANCES`, or stop holding weapons tight for the whole engage
window. **Both move `snapshot_hash` and re-score every archive** — a real decision, not a quick fix.

Guarded by `tests/skip_debt.rs::the_brain_barely_runs_so_two_skips_are_still_needed`, which pins that
ratio and fires when the tour is rebalanced. `ADVANCE_TICKS`/`ENGAGE_TICKS`/`DWELL_ADVANCES` are `pub` so
it can read them.

### C. The broadcast watch-threshold skip

`--skip watching_the_feed_makes_it_generate_and_ignoring_it_stops`. Unrelated and fully measured:
`broadcast.watch_threshold` (0.006) sits *inside* the ambient ATTENTION noise floor (0.0025–0.0067), so
every screen counts as watched forever. Raising it is not enough — `spawn_min_dist` (16 tiles) exceeds
`fog::VISION_RADIUS` (8), so a screen is seeded beyond the range its own mechanic can reach. Needs a
placement decision first. `BACKLOG.md` carries both measurements; guarded by the second `skip_debt` test.

## Traps that cost real time — do not repeat

1. **Never wrap `evaluate::rollout` in `serial_guard()`.** It takes the non-reentrant `HARNESS_LOCK`
   itself, so wrapping it **deadlocks silently** — it just looks like a slow test. `--test-threads=1`
   already serialises. `search_calibration.rs` documents this; I hit it anyway and lost a run to it.
2. **`cargo test --test a --test b` stops at the first failing binary.** Use `--no-fail-fast`, or run them
   separately, or you will "fix" one thing and never see the other.
3. **A prefix test filter matches more than you mean.** `--exact` matters: filtering on
   `deterministic_core_is_bit_identical` also ran `..._across_many_builds`, which aborts the whole process
   before your target test runs.
4. **`tests/skip_debt.rs` is a debt tripwire, not a test of the code.** One guard per CI `--skip`,
   asserting the skip's *reason* still holds. A red there means "somebody fixed the bug, delete the skip".
   Honour it — it caught me the moment I fixed the criterion.
5. **The dependency ratchets parse manifests by hand.** They read a dependency line's crate name by
   splitting on `= . ' '`. Both a dotted key (`serde.workspace = true`) and a multi-line
   `features = [...]` array tripped them; both are fixed, but if you add an unusual manifest shape, check.
6. **Verify "pre-existing" before blaming your change.** Two failures during this work looked like
   regressions and were not — stash the change, re-run at the prior commit, and only then form a
   hypothesis. The `search_parallel` header says the same thing after three wrong explanations.
